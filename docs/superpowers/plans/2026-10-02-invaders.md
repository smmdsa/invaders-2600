# INVADERS Implementation Plan

> Execute inline with superpowers:executing-plans; validate each deliverable before moving on.

**Goal:** A complete Atari-inspired campaign with native generated graphics and audio.
**Architecture:** A deterministic engine emits events; an independent canvas renderer and Web Audio synthesizer consume them. DOM controls own input and persistence.
**Tech Stack:** HTML, CSS, JavaScript, Canvas 2D, Web Audio, Node built-ins for tests/server.
**Spec:** ../specs/2026-10-02-invaders-design.md

## Global constraints
- No frameworks, dependencies, downloaded assets or fonts.
- 480×500 viewport, 8 pixel border, six enemy types, ten campaign stages.
- Three initial hearts; five heart, weapon, rate and shield caps.
- Files work over HTTP and by opening index.html directly.

## Review focus
- Held keys, lost focus and tab suspension must not cause stuck inputs or catch-up deaths.
- Sparse edge columns and detached divers must not distort formation bounds.
- Simultaneous hits and stage completion must not overwrite defeat.
- Corrupt or disabled storage must not prevent play or initials submission.
- Pointer release/cancel and narrow screens must preserve accessible controls.
